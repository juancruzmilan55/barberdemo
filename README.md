# Demo de reservas (versión estática)
Versión sin servidor: los datos son de ejemplo (`lib/demo/data.ts`) y las reservas se guardan en el navegador de cada visitante.

## Publicar en GitHub Pages
1. Subí esta carpeta a un repo de GitHub (rama `main`).
2. Repo > Settings > Pages > Source: **GitHub Actions**.
3. Cada push publica solo en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Probar en local
`npm install` y `npm run dev` (abrí http://localhost:3000).
